# Network and transit

> DRAFT — outline only.

- Name the network AND the subject noun in the query ("railway lines in Spain", "power plants in Texas by fuel type") — a bare adjective ("primary", "main") can be read as a different subject.
- Transit: say whether the map shows routes, stops or live vehicles; live positions only where the source provides them.
- Power plants: report capacity and fuel only as the source lists them.
- Not a routing service — for directions, say so and stop.
